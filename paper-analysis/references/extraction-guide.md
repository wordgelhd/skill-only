# 提取口径与打分说明约定

## 十个字段的提取口径

| 字段 | 口径 | 缺失时 |
| --- | --- | --- |
| 标题 | 逐字照录；去掉「网络首发」「免费」「增强出版」等平台后缀 | 用文件名 |
| 作者 | 全部作者，保持原文顺序，用「、」分隔 | 未提及 |
| 年份 | 发表年份，4 位数字 | 未提及 |
| 期刊 | 来源期刊全称 | 未提及 |
| 研究问题 | 一句话概括本文要回答的问题，用「本文研究/探讨/回答……」句式 | 未提及 |
| 理论框架 | 所依据的经济学/管理学理论（如资源基础观、制度理论、交易成本、信号理论） | 未提及 |
| 研究方法 | 核心方法（如因果推断、双重差分、复杂网络、文本分析、博弈论建模） | 未提及 |
| 数据来源 | 数据集名称 + 样本量 + 时间跨度，尽量写成「国泰安 2010–2020 上市公司 1.2 万条」式 | 未提及 |
| 主要发现 | 2–3 条核心结论，每条一句，编号列出 | 未提及 |
| 局限性 | 优先用作者自述；作者未述则基于方法/数据判断，并标注「（推断）」 | 未提及 |

原则：**逐字照录的（前四列）不改写，概括浓缩的（后六列）不编造**。判断不了就写「未提及」，
宁可留白也不要让不存在的样本量、年份、结论混进表格。

### 「理论框架」与「研究方法」怎么区分

两者最易混填，判断法：**问「这句话在回答 why 还是 how」**。

- 理论框架 = 用什么理论视角解释现象、回答「为什么成立/凭什么这么看」（经济学/管理学理论：
  资源基础观、制度理论、交易成本、信号理论、委托代理、动态能力……）。
- 研究方法 = 用什么技术手段做分析、回答「怎么做」（因果推断、双重差分、工具变量、复杂网络、
  文本分析、博弈论建模、结构方程、机器学习……）。

例：「本文基于交易成本理论」→ 理论框架；「采用双重差分法识别因果效应」→ 研究方法。
同一篇常两者都有，各填各的，不要只填一个。

### 英文文献

英文文献的元数据（标题/作者/期刊）与概括字段的翻译规则，见 `translation-guide.md`。
概括性字段（研究问题/理论框架/研究方法/主要发现/局限性）译为中文后按上表口径填写。

## 打分说明.md 的约定格式

使用者自备、只读。理想结构应包含：

1. **评分维度列表**：每个维度给出「名称 + 含义 + 分值范围或权重」。
2. **总分计算方式**：加权求和或直接加总，写明公式。
3. **打分锚点**：什么情况给高分、什么情况给低分（帮助一致地打分）。

执行时按已有部分进行，缺失的维度不臆造；若全文不含任何可量化维度，停下提醒使用者补充，
不要自行发明一套评分规则。

## 示例表格优先级

`reference/` 下的 `*.xlsx` 是对「输出格式」的界定：

- 先读每个文件的表头，判断它对应「文献信息表」还是「评分表」。
- 命中的，列名、列序、单位、格式一律以示例为准（示例少哪列就少哪列、多哪列就多哪列）。
- 没有对应示例，用 SKILL.md 里的默认列。
- 只把示例当格式模板，不要复制示例里的示例数据。
